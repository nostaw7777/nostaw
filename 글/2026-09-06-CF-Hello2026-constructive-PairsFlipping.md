# Codeforces Hello 2026 — 2183I2 Pairs Flipping (Hard Version)

## 요약

길이 n인 이진 문자열에서, 길이 i인 두 위치 (a, a+i)를 골라 동시에 반전시키는
연산으로 최대 n/2번 안에 전부 0으로 만드는 구성 문제.

풀이 흐름:

1. 구간을 앞(홀수 길이)/뒤(짝수 길이)로 나눠 독립적으로 소거
2. 재귀적으로 구간을 축소하면 간격이 구간 크기보다 커서 못 지우는 고립된
   1이 생기는데, 이게 최대 log₉(n/2)번 정도만 나온다는 게 핵심 관찰
3. 좌우 대칭 구간에 고립된 1이 남는 특수 케이스 F(A,B,C)는 A=B±1 근처
   몇 가지만 손으로 케이스 분석하면 나머지는 구간 축소로 환원됨
4. 구간 길이 ≤18인 기저사례는 O(n²2ⁿ) DP로 미리 최적해 계산

시간복잡도 O(n log n), 실제 연산 횟수는 최악 조건에서도 이론 상한(n/2)에
크게 못 미치는 수준으로 나온다.

## 왜 이걸 골랐나

강점 축(수학·구현·애드혹·constructive)에 정확히 걸리는 문제라 골랐다.
자료구조를 안 쓰고 "관찰 → 케이스 분석 → 재귀 축소 → 작은 기저사례 DP"로
끝까지 가는 구조가, 딱 해요체로 안 풀리는 문제들 특유의 결이다.
